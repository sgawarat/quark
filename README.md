# Quark

## これは何？

あなたのキー入力によって動作する仮想的なキーボードを常駐させるクロスプラットフォームなデスクトップアプリケーションです。キーボードエンジンとしてキーボードファームウェアライブラリである「[QMK](https://github.com/qmk/qmk_firmware)」を利用しており、キーを入れ替えるだけではない様々なカスタマイズを行うことができます。

## ビルド

### 必要なもの

- C++23をビルドできる環境（GCC または Clang）
- CMake（v3.28以上）
- [qmk_firmware](https://github.com/qmk/qmk_firmware) または [Windows向け修正版](https://github.com/sgawarat/qmk_firmware)

加えて、Linuxでは以下が必要になります。

- libudev
- Qt6（UIアプリケーションが必要な場合）

### 必要なこと

実行ファイルをビルドするには、以下のようなコマンドを実行します。

```sh
cmake -B build -DCMAKE_BUILD_TYPE=Release -DQMK_FIRMWARE_DIR=<QMKへのパス> -DQUARK_KEYBOARD=<キーボード名> -DQUARK_KEYMAP=<キーマップ名> && cmake --build build
```

ビルドした実行ファイルをコピーするには、以下のようなコマンドを実行します。

```sh
cmake --install build --prefix <インストール先>
```

### 出来上がるもの

#### quark

`quark`は仮想キーボードを動作させるコンソールアプリケーションです。特別な操作は必要なく、起動するだけで動作します。終了させるには、コンソールにCtrl-Cを送信してください。

Linuxでは、対象の`/dev/input/event*`からの読み取りと`/dev/uinput`への書き込みが可能である必要があります。

#### quark-ui

`quark-ui`はシステムトレイアイコンを表示するためのGUIアプリケーションです。トレイアイコンを右クリックするとコンテキストメニューが表示され、`quark`の起動・停止やアプリの終了を行うことができます。`quark-ui`から起動した`quark`はその実行ファイルと同じディレクトリにテキストファイルとしてログを出力します。

#### keytest

`keytest`はOSのキー表現を確認するための簡易的なプログラムです。

## 構成

### キーボード

*キーボード*は仮想キーボードの仕様を定義するものです。このソフトウェアをビルドするには、その名前を`QUARK_KEYBOARD`変数で指定する必要があります。*キーボード*は`keyboards`ディレクトリにあり、そこから`keymaps`の存在するディレクトリまでが名前になります。実装の詳細は`keyboards`ディレクトリを参照してください。

### キーマップ

*キーマップ*は仮想キーボードの挙動を定義するものです。このソフトウェアをビルドするには、その名前を`QUARK_KEYMAP`変数で指定する必要があります。*キーマップ*は`keyboards/<キーボード名>/keymaps`ディレクトリにあり、そこから`keymap.c`の存在するディレクトリまでが名前になります。実装の詳細は`keyboards`ディレクトリを参照してください。

## 既知の問題

### Windows

#### 管理者権限のアプリケーション上で機能しない

このアプリケーションを管理者権限で起動することによって解消されます。これは、一般権限で起動したアプリケーションが管理者権限のキー入力を取得できない仕様によるものです。

同様に、ストアアプリなどでも権限の関係で上手く機能しない可能性があります。

#### 他のキーマッピングツールとともに機能しない

このアプリケーションを最後に起動すると解消されるかもしれません。これは、後に起動したアプリが優先してキー入力を取得できる仕様によるものです。

### Linux

#### アプリが全く機能しない・起動しない

Linux版は`/dev/input/event*`からの読み取りと`/dev/uinput`への書き込みを行える権限が必要です。

#### たまに機能しないときがある

アプリ起動後やデバイス接続後にキーボードから手を離すようにすると解消されるかもしれません。これは、すべてのキーが離された状態を確認してから動作を開始するという、誤動作を避ける仕組みによるものです。
