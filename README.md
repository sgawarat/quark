# Quark

## これは何？

あなたのキー入力によって動作する仮想的なキーボードを常駐させるデスクトップアプリケーションです。キーボードエンジンとしてキーボードファームウェアライブラリである「[QMK](https://github.com/qmk/qmk_firmware)」を利用しており、キーを入れ替えるだけではない様々なカスタマイズを行うことができます。

## ビルド

### 必要なもの

- C++20をビルドできる環境（GCC または Clang）
- CMake（v3.18以上）
- [qmk_firmware](https://github.com/qmk/qmk_firmware)
  - または [MSVC向け修正版](https://github.com/sgawarat/qmk_firmware)

### 必要なこと

- `QMK_FIRMWARE_DIR`変数にqmk_firmwareへのパスを指定します。
- `QUARK_LAYOUT_DIR`変数にレイアウトへのパスを指定します。
- `QUARK_KEYMAP_DIR`変数にキーマップへのパスを指定します。

## 構成

### レイアウト

レイアウトは物理キーボードと仮想キーボードの橋渡しを行うものです。このソフトウェアでは、`QUARK_LAYOUT_DIR`で指定されるディレクトリにてビルドされる`layout`というライブラリをレイアウトとしてリンクします。既存の実装は`layouts`ディレクトリ以下に用意されています。

### キーマップ

キーマップは仮想キーボードの振る舞いを定義するもので、QMKのキーマップを流用できるように設計されています。このソフトウェアでは、`QUARK_KEYMAP_DIR`で指定されるディレクトリにてビルドされる`keyboard`というライブラリをキーマップとしてリンクします。作例は`keyboards`ディレクトリ以下に用意されています。

## 既知の問題

### Windows

#### 管理者権限のアプリケーション上で機能しない

このアプリケーションを管理者権限で起動することによって解消できます。これは、一般権限で起動したアプリケーションが管理者権限のキー入力を取得できない仕様によるものです。

#### 他のキーマッピングツールとともに機能しない

このアプリケーションを最後に起動すると解消するかもしれません。これは、先に起動したアプリが優先してキー入力取得処理を行うことができる仕様によるものです。
