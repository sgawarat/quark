# Quark

## これは何？

あなたのキー入力によって動作する仮想的なキーボードを常駐させるデスクトップアプリケーションです。キーボードエンジンとしてキーボードファームウェアライブラリである「[QMK](https://github.com/qmk/qmk_firmware)」を利用しており、キーを入れ替えるだけではない様々なカスタマイズを行うことができます。

## ビルド

### 必要なもの

- C++20をビルドできる環境（GCC または Clang）
- CMake（v3.18以上）
- [qmk_firmware](https://github.com/qmk/qmk_firmware)
  - または [MSVC向け修正版](https://github.com/sgawarat/qmk_firmware)

### 必要なこと

- `QMK_FIRMWARE_DIR`変数にqmk_firmwareへのパスを指定します。
- `QUARK_KEYBOARD`変数にキーボードの名前を指定します。
- `QUARK_KEYMAP`変数にキーマップの名前を指定します。

## 構成

### キーボード

*キーボード*は仮想キーボードの仕様を定義するものです。このソフトウェアをビルドするには、その名前を`QUARK_KEYBOARD`変数で指定する必要があります。*キーボード*は`keyboards`ディレクトリにあり、そこから`keymap.h`の存在するディレクトリまでが名前になります。実装の詳細は`keyboards`ディレクトリを参照してください。

### キーマップ

*キーマップ*は仮想キーボードの挙動を定義するものです。このソフトウェアをビルドするには、その名前を`QUARK_KEYMAP`変数で指定する必要があります。*キーマップ*は`keyboards/<キーボード名>/keymaps`ディレクトリにあり、そこから`keymap.c`の存在するディレクトリまでが名前になります。実装の詳細は`keyboards`ディレクトリを参照してください。

## 既知の問題

### Windows

#### 管理者権限のアプリケーション上で機能しない

このアプリケーションを管理者権限で起動することによって解消されます。これは、一般権限で起動したアプリケーションが管理者権限のキー入力を取得できない仕様によるものです。

#### 他のキーマッピングツールとともに機能しない

このアプリケーションを最後に起動すると解消されるかもしれません。これは、先に起動したアプリが優先してキー入力を取得できる仕様によるものです。
