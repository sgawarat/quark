# バインディング

QuarkはOSのキー表現とQMKのキー表現の橋渡しを行いますが、一部の関数はユーザーで実装する必要があります。

## key_to_keypos関数

QuarkはOSのキー表現を連続的に再配置した`Key`型（[key.hpp](../include/quark/key.hpp)）としてキー入力を表現します。一方、QMKはキーをMatrixという二次元配列上の位置として表現します。Matrixにおけるキー配置は*キーボード*によって定義されるので、この`Key`型の値とQMKのMatrix上の位置の対応関係は*キーボード*または*キーマップ*によって定義されなければなりません。Quarkでは、この対応関係を`key_to_keypos`関数として表現しており、これを実装する場所として`keyboard`ライブラリや`keymap`ライブラリといった仕組みが用意されています。その詳細については[keyboards](keyboards.md)や[keymaps](keymaps.md)を参照してください。

### is_tapping_key関数

OSによって（特にWindowsで）は、離したときにKEYUPイベントを発生させないキーが存在します。そのようなキーは"押すと同時に離す"キーとして扱われる必要があり、Quarkでは`is_tapping_key`関数を実装することでその機能を有効化できます。この関数はOSの仕様に従って事前に定義できるはずですが、各言語でどのような違いがあるかを確認できていないため、その判断はユーザーにおまかせするかたちとなっています。
